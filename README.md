# 🎉 Template Undangan Digital - FDGallery.id

Repositori ini berisi **template undangan digital berbasis web**.  
Template ini dapat digunakan sebagai dasar untuk membuat undangan pernikahan, ulang tahun, atau acara lainnya.  

> ⚠️ Catatan: Project ini hanya **template** (contoh), bukan produk final.  
Silakan edit sesuai kebutuhan masing-masing pengguna.

---

## ✨ Fitur Template
- Tampilan **cover undangan** dengan tombol "Buka Undangan"
- **Animasi scroll** menggunakan AOS.js
- **Musik background** yang otomatis diputar ketika undangan dibuka
- **Countdown acara** (hitung mundur menuju hari H)
- **Galeri foto** dengan fitur fullscreen
- **RSVP form** (bisa dihubungkan ke database / email)
- **Footer dengan link sosial media**
- Desain responsif (bisa dibuka di HP & Laptop)

---

## 🛠️ Teknologi
- **HTML5** → struktur halaman  
- **CSS3 + Bootstrap 5** → styling & responsif  
- **JavaScript** → interaksi (musik, animasi, gallery)  
- **PHP + MySQL** (opsional) → jika ingin menyimpan data RSVP
